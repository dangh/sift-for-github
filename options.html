PR Files Tabs

A tab shows a file when any of its patterns match. One pattern per line. A glob like package*.json matches the file name only (* = any characters, ? = one character). A glob with a slash like services/*/lib/* matches the full path. /regex/flags such as /test/i matches the full path.
Exclude with !: !Metadata drops files that belong to the Metadata tab, !*.md drops files matching that pattern. A tab with only ! lines starts from every file.

The tab you pick on a PR is remembered for that PR across refreshes. This only applies to PRs you open fresh.

Experiments

When a PR opens on a tab other than All, switch GitHub to the list it uses for very large PRs, which loads diffs as you scroll to them instead of fetching every file first. Files in other tabs are skipped until you show them. Trade-off: Find on Page only sees diffs near the screen.

When GitHub does fetch every file (a PR opened on All, or with the option above off), fetch them in parallel instead of one request at a time and hand them to GitHub as it asks.

Experiments take effect on the next page load.
